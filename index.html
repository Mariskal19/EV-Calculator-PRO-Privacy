Política de privacidad — EV Calculator PRO

Última actualización: 24 de agosto de 2026

1. Información general

EV Calculator PRO es una aplicación Android destinada a realizar cálculos relacionados con la carga de vehículos eléctricos, incluyendo el tiempo de carga, el coste estimado y la hora de inicio recomendada.

Para cualquier consulta relacionada con privacidad o protección de datos, puede contactar con el desarrollador en Mariskal19@hotmail.com.

2. Datos que recopila la aplicación

EV Calculator PRO no recopila ni transmite datos personales de los usuarios.

La aplicación no requiere la creación de una cuenta ni un inicio de sesión y no solicita información personal como nombre, dirección de correo electrónico para utilizar la aplicación, número de teléfono, dirección postal, ubicación, contactos, fotografías, cámara o micrófono.

3. Datos introducidos por el usuario

Para realizar sus cálculos, la aplicación permite introducir datos relacionados con la carga del vehículo, como capacidad de batería, porcentaje de carga inicial, porcentaje de carga objetivo, potencia de carga, precio de la energía, hora de salida y configuración de consumo de Centinela/XGuard.

Estos datos se utilizan exclusivamente para realizar los cálculos y mostrar los resultados correspondientes.

4. Almacenamiento de datos

Algunos valores introducidos por el usuario se almacenan localmente en el propio dispositivo para conservar las preferencias entre sesiones.

Estos datos no se envían a servidores del desarrollador ni a terceros.

5. Compartición de datos

EV Calculator PRO no vende, alquila ni comparte datos personales de los usuarios con terceros.

La versión actual tampoco utiliza servicios de publicidad, perfiles de usuario o herramientas de seguimiento destinadas a recopilar información personal.

6. Conexión a Internet

Las funciones principales de EV Calculator PRO se realizan localmente en el dispositivo y no requieren que el usuario cree una cuenta ni envíe sus datos personales a un servidor.

7. Servicios de terceros

La versión actual de EV Calculator PRO no incorpora servicios de terceros destinados a recopilar datos personales de los usuarios.

Si en el futuro se incorporasen servicios de terceros que recopilen, procesen o compartan datos de los usuarios, esta política de privacidad se actualizará para describir dichos servicios y su tratamiento de datos.

8. Publicidad

La versión actual de EV Calculator PRO no contiene publicidad.

En el futuro, el desarrollador podría incorporar publicidad, por ejemplo mediante banners u otros formatos publicitarios.

Si se incorpora publicidad que implique el tratamiento, recopilación o compartición de datos del usuario por parte de proveedores publicitarios, esta política de privacidad será actualizada para identificar los servicios utilizados y explicar el tratamiento correspondiente. Asimismo, se actualizará la información declarada en Google Play cuando sea necesario.

9. Seguridad

Los datos de configuración almacenados por la aplicación permanecen localmente en el dispositivo y no son transmitidos al desarrollador.

La seguridad de dichos datos también depende de las medidas de seguridad y protección configuradas por el usuario en su dispositivo Android.

10. Conservación y eliminación de datos

Los datos de configuración local se conservan en el dispositivo mientras sean necesarios para mantener las preferencias de la aplicación.

El usuario puede eliminar estos datos desde los ajustes de Android, utilizando las opciones de almacenamiento de la aplicación, o desinstalando EV Calculator PRO.

La aplicación no mantiene actualmente una cuenta de usuario ni una base de datos externa asociada al usuario.

11. Menores

EV Calculator PRO no está diseñada específicamente para recopilar información personal de menores y no solicita datos personales para utilizar sus funciones.

12. Cambios en esta política

Esta política de privacidad podrá actualizarse cuando se modifiquen las funcionalidades de EV Calculator PRO o sus prácticas de tratamiento de datos.

La fecha de la última actualización se indicará al principio de esta política.

Si en el futuro se incorporan nuevas funcionalidades que impliquen recopilación, uso o compartición de datos, esta política se actualizará para reflejar dichas prácticas.

13. Contacto

Para cualquier consulta relacionada con la privacidad o el tratamiento de datos de EV Calculator PRO, puede contactar con el desarrollador mediante Mariskal19@hotmail.com.
