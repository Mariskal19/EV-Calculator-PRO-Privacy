Política de privacidad — EV Calculator PRO

Última actualización: 26 de noviembre de 2026

1. Información general

EV Calculator PRO es una aplicación Android destinada a realizar cálculos relacionados con la carga de vehículos eléctricos, incluyendo el tiempo de carga, el coste estimado y la hora de inicio recomendada.

Para cualquier consulta relacionada con privacidad o protección de datos, puede contactar con el desarrollador en Mariskal19@hotmail.com.

2. Datos que recopila la aplicación

EV Calculator PRO no solicita datos personales para utilizar sus funciones y no envía al desarrollador los datos que el usuario introduce para realizar los cálculos.

La aplicación no requiere crear una cuenta ni iniciar sesión, y no solicita nombre, correo electrónico, número de teléfono, dirección postal, ubicación, contactos, fotografías, cámara o micrófono.

La aplicación realiza conexiones a Internet para descargar información pública necesaria para algunas funciones. Como ocurre con las conexiones a servicios web, los servidores consultados pueden recibir datos técnicos de la conexión, como la dirección IP, la fecha y hora de la solicitud, el recurso solicitado y determinados datos técnicos incluidos en la petición. Estos datos técnicos son tratados por los proveedores de dichos servicios conforme a sus propias políticas. EV Calculator PRO no utiliza la dirección IP para identificar, perfilar o determinar la ubicación del usuario.

3. Datos introducidos por el usuario

Para realizar sus cálculos, la aplicación permite introducir datos relacionados con la carga del vehículo, como capacidad de batería, porcentaje de carga inicial, porcentaje de carga objetivo, potencia de carga, precio de la energía, hora de salida y configuración de consumo de Centinela/XGuard.

Estos datos se utilizan exclusivamente en el dispositivo para realizar los cálculos y mostrar los resultados correspondientes. No se incluyen en las solicitudes de descarga del catálogo de vehículos ni de los tipos de cambio descritas en esta política.

4. Almacenamiento de datos

Algunos valores introducidos por el usuario se almacenan localmente en el propio dispositivo para conservar las preferencias entre sesiones.

Los datos de cálculo y las preferencias almacenadas localmente no se envían a servidores del desarrollador ni a los proveedores externos utilizados para descargar información pública.

5. Compartición de datos

EV Calculator PRO no vende ni alquila datos personales de los usuarios. Tampoco comparte con terceros los datos introducidos para los cálculos ni las preferencias almacenadas en el dispositivo.

Para descargar información pública, la aplicación se conecta a los servicios indicados en los apartados siguientes. Esos proveedores pueden recibir los datos técnicos necesarios para atender las solicitudes web, tal como se explica en el apartado 2. Esto no implica que la aplicación les envíe los datos de carga introducidos por el usuario.

La versión actual no contiene publicidad ni utiliza perfiles de usuario o herramientas de seguimiento publicitario.

6. Conexión a Internet e información descargada

Las funciones de cálculo principales se realizan localmente en el dispositivo. La conexión a Internet se utiliza para obtener información pública que complementa algunas funciones:

  • Catálogo de vehículos: la aplicación descarga un archivo de catálogo alojado en GitHub, desde el repositorio público de EV Calculator PRO. La comprobación del catálogo remoto se limita a la frecuencia configurada por la aplicación.
  • Tipos de cambio: la aplicación consulta la API pública del Banco Central Europeo (BCE) para descargar cotizaciones de divisas y poder mostrar determinados precios del catálogo en otras monedas.

Estas solicitudes son peticiones de descarga de información pública. No incluyen los porcentajes de batería, la capacidad introducida, la potencia de carga, el precio de energía introducido, la hora de salida, las preferencias de cálculo ni los resultados obtenidos.

Los proveedores de estos servicios pueden tratar metadatos técnicos de las solicitudes, incluida la dirección IP, de acuerdo con sus propias políticas de privacidad y condiciones.

7. Servicios de terceros

La aplicación utiliza servicios externos únicamente como fuentes de información pública:

  • GitHub: alojamiento y descarga del catálogo remoto de vehículos de EV Calculator PRO.
  • Banco Central Europeo (BCE): consulta de datos públicos de tipos de cambio a través de su API.

La aplicación no incorpora actualmente SDK de publicidad ni servicios de analítica o seguimiento destinados a crear perfiles de usuario. Los proveedores externos pueden tratar los datos técnicos de conexión que reciben al atender las solicitudes, conforme a sus propias políticas. EV Calculator PRO no les transmite los datos introducidos para los cálculos.

8. Publicidad

La versión actual de EV Calculator PRO no contiene publicidad.

En el futuro, el desarrollador podría incorporar publicidad, por ejemplo mediante banners u otros formatos publicitarios.

Si se incorpora publicidad que implique el tratamiento, recopilación o compartición de datos del usuario por parte de proveedores publicitarios, esta política de privacidad será actualizada para identificar los servicios utilizados y explicar el tratamiento correspondiente. Asimismo, se actualizará la información declarada en Google Play cuando sea necesario.

9. Seguridad

Los datos de configuración almacenados por la aplicación permanecen localmente en el dispositivo y no son transmitidos al desarrollador ni a los proveedores externos descritos en esta política.

La seguridad de dichos datos también depende de las medidas de seguridad y protección configuradas por el usuario en su dispositivo Android.

10. Conservación y eliminación de datos

Los datos de configuración local se conservan en el dispositivo mientras sean necesarios para mantener las preferencias de la aplicación.

El usuario puede eliminar estos datos desde los ajustes de Android, utilizando las opciones de almacenamiento de la aplicación, o desinstalando EV Calculator PRO.

La aplicación no mantiene actualmente una cuenta de usuario ni una base de datos externa asociada al usuario.

11. Menores

EV Calculator PRO no está diseñada específicamente para recopilar información personal de menores y no solicita datos personales para utilizar sus funciones.

12. Cambios en esta política

Esta política de privacidad podrá actualizarse cuando se modifiquen las funcionalidades de EV Calculator PRO o sus prácticas de tratamiento de datos.

La fecha de la última actualización se indicará al principio de esta política.

Si en el futuro se incorporan nuevas funcionalidades que impliquen recopilación, uso o compartición de datos, esta política se actualizará para reflejar dichas prácticas.

13. Contacto

Para cualquier consulta relacionada con la privacidad o el tratamiento de datos de EV Calculator PRO, puede contactar con el desarrollador mediante Mariskal19@hotmail.com.
